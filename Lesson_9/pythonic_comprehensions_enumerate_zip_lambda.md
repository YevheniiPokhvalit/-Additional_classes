## Частина 1: Генератори списків та словників (Comprehensions)

**List Comprehension** (*скорочення списків / генератор списків*) — це синтаксична конструкція, яка дозволяє створити новий список на основі існуючої послідовності в один рядок (замість 3–5 рядків звичайного циклу `for` з `.append()`). Крім стислості, він працює швидше на рівні інтерпретатора.

### 1. Базова формула трансформації

```python
[вираз for елемент in послідовність]
```

```python
# Класичний спосіб (4 рядки):
squares = []
for x in range(1, 6):
    squares.append(x ** 2)

# Pythonic-спосіб (1 рядок):
squares = [x ** 2 for x in range(1, 6)]
# Результат: [1, 4, 9, 16, 25]
```

### 2. Генератор із фільтрацією (`if` у кінці)

Додає елемент у новий список тільки тоді, коли виконується умова.

```python
[вираз for елемент in послідовність if умова]
```

```python
numbers = [12, -5, 8, -1, 0, 24, -9, 15]

# Відбираємо лише додатні числа:
positives = [n for n in numbers if n > 0]
# Результат: [12, 8, 24, 15]
```

### 3. Генератор із заміною за умовою (`if-else` на початку)

Коли ми не відкидаємо елементи, а змінюємо їх залежно від умови (тернарний оператор).

```python
[вираз_якщо_True if умова else вираз_якщо_False for елемент in послідовність]
```

```python
grades = [10, 4, 12, 5, 9]

# Маркуємо оцінки як "Зарах" (від 6 балів) або "Незарах":
status = ["Зарах" if g >= 6 else "Незарах" for g in grades]
# Результат: ['Зарах', 'Незарах', 'Зарах', 'Незарах', 'Зарах']
```

### 4. Генератори словників (Dict Comprehensions)

Працюють за тим самим принципом, але у фігурних дужках `{}` і з двокрапкою `ключ: значення`.

```python
words = ["яблуко", "груша", "ківі"]

# Словник, де ключ — слово, а значення — його довжина:
word_lengths = {w: len(w) for w in words}
# Результат: {'яблуко': 6, 'груша': 5, 'ківі': 4}
```

> 💡 **Золоте правило чистого коду:**
> Якщо List Comprehension стає довшим за 80 символів або містить 2–3 вкладені цикли — його стає важко читати. У таких випадках краще повернутися до звичайного циклу `for`.

## Частина 2: Функції `enumerate()` та `zip()`

### 1. Функція `enumerate(iterable, start=0)`

Часто під час перебору списку потрібен і сам елемент, і його порядковий номер (індекс). Початківці пишуть `for i in range(len(items)):`, що у Python вважається поганим тоном.

`enumerate()` на кожному кроці повертає пару `(індекс, значення)`, яку зручно розпаковувати одразу в циклі:

```python
tasks = ["Купити хліб", "Вивчити Python", "Зробити зарядку"]

# Антипатерн (як НЕ треба):
for i in range(len(tasks)):
    print(f"{i + 1}. {tasks[i]}")

# Pythonic-спосіб через enumerate (start=1 задає початок нумерації з одиниці):
for index, task in enumerate(tasks, start=1):
    print(f"{index}. {task}")
```

### 2. Функція `zip(iter1, iter2, ...)`

Назва походить від англ. *zipper* (застібка-блискавка). Вона бере декілька списків і «зшиває» їхні елементи з однаковими індексами у кортежі: перший з першим, другий з другим і так далі.

```python
names = ["Олексій", "Марія", "Дмитро"]
scores = [95, 100, 88]

# Одночасний перебір двох списків:
for name, score in zip(names, scores):
    print(f"Учень {name} набрав {score} балів")

# Суперсила zip — миттєве створення словника з двох списків:
students_dict = dict(zip(names, scores))
# {'Олексій': 95, 'Марія': 100, 'Дмитро': 88}
```

> ⚠️ **Нюанс:** якщо списки різної довжини, `zip()` зупиниться тоді, коли закінчиться найкоротший список.

## Частина 3: Анонімні функції `lambda`

`lambda`-функція — це маленька однорядкова функція без імені (анонімна), яку створюють «на льоту» для простих операцій.

* **Синтаксис:** `lambda параметри: вираз_який_повертається`
* У ній не пишеться слово `return` — результат виразу після двокрапки повертається автоматично.

```python
# Звичайна функція:
def double(x):
    return x * 2

# Те саме через lambda:
double_lambda = lambda x: x * 2
print(double_lambda(5))  # 10
```

### Де `lambda` справді незамінна?

На практиці `lambda` майже ніколи не присвоюють у змінну (для цього є `def`). Її головна роль — передача як аргументу `key=` у функції сортування та пошуку (`sorted()`, `.sort()`, `min()`, `max()`), коли потрібно вказати, за яким саме правилом або полем порівнювати складні об'єкти.

```python
# Маємо список товарів (список словників):
products = [
    {"name": "Мишка", "price": 650},
    {"name": "Ноутбук", "price": 28000},
    {"name": "Клавіатура", "price": 1800}
]

# Як відсортувати товари за ціною від найдешевшого до найдорожчого?
# Передаємо lambda, яка каже: "Для кожного елемента p бери його поле p['price']"
sorted_products = sorted(products, key=lambda p: p["price"])
for item in sorted_products:
    print(f"{item['name']}: {item['price']} грн")

# Пошук найдорожчого товару в один рядок:
most_expensive = max(products, key=lambda p: p["price"])
print("Найдорожчий лот:", most_expensive["name"])
```

## 4. Зведена таблиця Pythonic-інструментів

| Інструмент | Яку проблему вирішує | Приклад синтаксису |
| :--- | :--- | :--- |
| **List Comprehension** | Замінює цикл `for` + `.append()` для генерації списку | `[x * 2 for x in nums if x > 0]` |
| **Dict Comprehension** | Створює або трансформує словник в один рядок | `{k: v * 2 for k, v in d.items()}` |
| **`enumerate()`** | Дає одночасно доступ до індексу та значення елемента | `for i, val in enumerate(lst, 1):` |
| **`zip()`** | Поєднує декілька послідовностей для паралельного проходу | `for a, b in zip(list1, list2):` |
| **`lambda`** | Задає швидке правило сортування чи вибору (`key=`) | `sorted(users, key=lambda u: u[1])` |
