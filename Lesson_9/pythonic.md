# Практичні завдання на закріплення

## Завдання 1: «Рефакторинг коду в один рядок» (`List Comprehensions`)

* **Мета:** перетворення та фільтрація даних без класичних циклів.

* **Умова:**
  Дано список цін у гривнях:

  ```
  prices = [100, 250, 80, 1200, 45, 600, 30]
  
  ```

  Використовуючи виключно **List Comprehensions**, створіть три нові списки:

  1. `prices_with_tax` — усі ціни, збільшені на 20% (помножені на `1.2`).

  2. `expensive_items` — тільки ті ціни з початкового списку, які більші за 200 грн.

  3. `labels` — список рядків `"Дорого"` (якщо ціна $> 200$) або `"Доступно"` (якщо $\le 200$) для кожного елемента.

## Завдання 2: «Генератор табеля успішності» (`zip` та `enumerate`)

* **Мета:** поєднання списків, створення словника та нумерований вивід.

* **Умова:**
  Дано два окремі списки:

  ```
  subjects = ["Інформатика", "Математика", "Фізика", "Англійська"]
  grades = [12, 10, 9, 11]
  
  ```

  1. За допомогою `enumerate()` та `zip()` виведіть нумерований звіт (починаючи з 1):

     ```
     1. Інформатика — 12 балів
     2. Математика — 10 балів
     ...
     
     ```

  2. В один рядок перетворіть ці два списки на словник `report_card` за допомогою `dict(zip(...))`.

  3. За допомогою **Dict Comprehension** створіть новий словник `excellent_subjects`, куди увійдуть лише предмети з оцінкою 10 і вище.

## Завдання 3: «Рейтинг кіберспортивної ліги» (`lambda` + `sorted` + `min`)

* **Мета:** сортування списку словників/кортежів за власним ключем.

* **Умова:**
  Дано список команд у форматі кортежів `(назва_команди, перемоги, очки)`:

  ```
  teams = [("NaVi", 12, 36), ("Monte", 10, 30), ("Fnatic", 8, 24), ("Vitality", 14, 42)]
  
  ```

  1. Відсортуйте список команд за кількістю очок (індекс `2`) за спаданням (`reverse=True`), використавши `sorted()` та `lambda`.

  2. Знайдіть команду з найменшою кількістю перемог за допомогою функції `min()` та `lambda`.

  3. Виведіть турнірну таблицю.

## Завдання 4: Мініпроєкт — «Аналізатор кошика інтернет-магазину» (Комплексне)

* **Мета:** поєднання всіх інструментів уроку в єдиному сценарії.

* **Умова:**
  Дано кошик замовлення:

  ```
  cart = [
      {"title": "Ардуїно Uno", "price": 450, "qty": 2},
      {"title": "Набір резисторів", "price": 120, "qty": 5},
      {"title": "Паяльник", "price": 950, "qty": 1},
      {"title": "Макетна плата", "price": 180, "qty": 3}
  ]
  
  ```

  1. Відсортуйте товари в кошику за загальною вартістю позиції (`price * qty`) від найдорожчої до найдешевшої за допомогою `lambda`.

  2. Виведіть чек із порядковими номерами через `enumerate(..., start=1)`.

  3. За допомогою генератора порахуйте загальну суму чека в один рядок через `sum()`.

  4. Створіть список назв (`title`) лише тих товарів, яких замовили більше ніж 2 штуки (`qty > 2`), використавши **List Comprehension**.
