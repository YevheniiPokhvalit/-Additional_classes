Повний довідник вбудованих методів list
Всього в Python є 11 вбудованих методів типу list.

1. Додавання елементів
.append(x) — додає один елемент x у кінець списку.
.extend(iterable) — розширює список, додаючи по черзі всі елементи з іншої колекції.
.insert(index, x) — вставляє елемент x на вказану позицію index.
******************************
fruits = ["яблуко", "банан"]
fruits.append("груша")
# ['яблуко', 'банан', 'груша']

fruits.extend(["ківі", "слива"])
# ['яблуко', 'банан', 'груша', 'ківі', 'слива']

fruits.insert(1, "апельсин")  - стає на індекс 1, інші зсуваються праворуч
# ['яблуко', 'апельсин', 'банан', 'груша', 'ківі', 'слива']
******************************

2. Видалення елементів**
.remove(x) — видаляє перше входження значення x. Якщо елемента немає — виникає помилка ValueError.
.pop([index]) — видаляє елемент за індексом і повертає його. Якщо індекс не вказано, видаляє та повертає останній елемент.
.clear() — повністю очищає список (робить його порожнім []).

******************************
items = ["зошит", "ручка", "олівець", "ручка"]
items.remove("ручка")  # видалить тільки першу "ручку"
# ['зошит', 'олівець', 'ручка']
deleted_item = items.pop(0)  # видаляє 'зошит' і записує його в змінну
# deleted_item = 'зошит', items = ['олівець', 'ручка']
items.clear()
# items = []
******************************

3. Пошук та підрахунок
.count(x) — рахує, скільки разів значення x зустрічається в списку.

.index(x, [start, [stop]]) — повертає індекс першого входження елемента x. Якщо елемента немає — виникає ValueError.

******************************
scores = [10, 12, 8, 12, 9, 12]

print(scores.count(12))  # 3
print(scores.index(8))   # 2 (індекс першої вісімки)
******************************

4. Зміна порядку та сортування
.sort(key=None, reverse=False) — сортує список на місці (мутує сам об'єкт, повертає None).
.reverse() — розгортає елементи списку у зворотному порядку на місці.

******************************
nums = [42, 11, 88, 3, 25]
nums.sort()
# [3, 11, 25, 42, 88]
nums.sort(reverse=True)
# [88, 42, 25, 11, 3]
words = ["кіт", "ананас", "пес"]
words.reverse()
# ['пес', 'ананас', 'кіт']
******************************
Поширена пастка : a = nums.sort(). У змінній a буде None, бо .sort() не повертає новий список, а змінює старий. 
Якщо потрібен новий список без зміни оригіналу — використовується функція sorted(nums).

5. Копіювання
.copy() — створює поверхневу копію списку (аналог зрізу nums[:]).

******************************
a = [1, 2, 3]
b = a         # НЕ копія! Обидві змінні посилаються на одну область пам'яті
c = a.copy()  # Справжня незалежна копія
b.append(4)
print(a)  # [1, 2, 3, 4] — 'a' змінився разом із 'b'!
print(c)  # [1, 2, 3] — 'c' лишився неушкодженим
******************************
