# #️⃣ Теоретичний блок та приклади

**Список (list)** — це впорядкована, змінювана колекція довільних об'єктів. Елементи записуються у квадратних дужках `[]` через кому.

## 🛠️ Створення списків
```python
empty = []                              # Порожній список
numbers = [10, 20, 30]                  # Список чисел
mixed = [1, "Python", 3.14, True]       # Список із різними типами даних
```

---

## 📚 Повний довідник вбудованих методів `list`

Всього в Python є **11 вбудованих методів** типу `list`.

### 1. Додавання елементів

* `.append(x)` — додає один елемент `x` у кінець списку.
* `.extend(iterable)` — розширює список, додаючи по черзі всі елементи з іншої колекції (наприклад, іншого списку).
* `.insert(index, x)` — вставляє елемент `x` на вказану позицію `index`.

**Приклад використання:**
```python
fruits = ["яблуко", "банан"]

fruits.append("груша")  
# Результат: ['яблуко', 'банан', 'груша']  

fruits.extend(["ківі", "слива"])
# Результат: ['яблуко', 'банан', 'груша', 'ківі', 'слива']

fruits.insert(1, "апельсин")  # Стає на індекс 1, інші зсуваються праворуч  
# Результат: ['яблуко', 'апельсин', 'банан', 'груша', 'ківі', 'слива']
```

### 2. Видалення елементів

* `.remove(x)` — видаляє перше входження значення `x`. Якщо елемента немає — виникає помилка `ValueError`.
* `.pop([index])` — видаляє елемент за індексом і повертає його. Якщо індекс не вказано, видаляє та повертає останній елемент.
* `.clear()` — повністю очищає список, роблячи його порожнім `[]`.

**Приклад використання:**
```python
items = ["зошит", "ручка", "олівець", "ручка"]

items.remove("ручка")  # Видалить тільки першу "ручку"  
# Результат: ['зошит', 'олівець', 'ручка']

deleted_item = items.pop(0)  # Видаляє 'зошит' і повертає його
# Результат: deleted_item = 'зошит', items = ['олівець', 'ручка']

items.clear()  
# Результат: items = []
```

### 3. Пошук та підрахунок

* `.count(x)` — рахує, скільки разів значення `x` зустрічається в списку.
* `.index(x, [start, [stop]])` — повертає індекс першого входження елемента `x`. Якщо елемента немає — виникає `ValueError`.

**Приклад використання:**
```python
scores = [10, 12, 8, 12, 9, 12]

print(scores.count(12))  # Виведе: 3
print(scores.index(8))   # Виведе: 2 (індекс першої вісімки)
```

### 4. Зміна порядку та сортування

* `.sort(key=None, reverse=False)` — сортує список на місці (мутує сам об'єкт, повертає `None`).
* `.reverse()` — розгортає елементи списку у зворотному порядку на місці.

**Приклад використання:**
```python
nums = [42, 11, 88, 3, 25]

nums.sort()  
# Результат: [3, 11, 25, 42, 88]

nums.sort(reverse=True)  
# Результат: [88, 42, 25, 11, 3]

words = ["кіт", "ананас", "пес"]
words.reverse()  
# Результат: ['пес', 'ананас', 'кіт']
```

> ⚠️ **Поширена пастка:** `a = nums.sort()`. У змінній `a` буде `None`, бо `.sort()` не створює новий список, а змінює оригінальний. Якщо потрібен новий список без зміни оригіналу — використовуйте вбудовану функцію `sorted(nums)`.

### 5. Копіювання

* `.copy()` — створює поверхневу копію списку (аналог зрізу `nums[:]`).

**Приклад використання:**
```python
a = [1, 2, 3]
b = a          # НЕ копія! Обидві змінні посилаються на одну область пам'яті
c = a.copy()   # Справжня незалежна копія

b.append(4)
print(a)       # Виведе: [1, 2, 3, 4] — 'a' змінився разом із 'b'!
print(c)       # Виведе: [1, 2, 3] — 'c' лишився неушкодженим
```

## 📊 Зведена таблиця методів

| Метод | Що робить | Чи повертає значення? |
| :--- | :--- | :--- |
| `list.append(x)` | Додає елемент у кінець | Ні (`None`) |
| `list.extend(iter)` | Додає всі елементи з ітерованого об'єкта в кінець | Ні (`None`) |
| `list.insert(i, x)` | Вставляє елемент на позицію i | Ні (`None`) |
| `list.remove(x)` | Видаляє перше входження x | Ні (`None`) |
| `list.pop([i])` | Видаляє елемент на позиції i (за замовчуванням останній) | Так (видалений елемент) |
| `list.clear()` | Видаляє всі елементи | Ні (`None`) |
| `list.index(x)` | Шукає перший індекс елемента x | Так (ціле число) |
| `list.count(x)` | Рахує кількість елементів x | Так (ціле число) |
| `list.sort()` | Сортує список на місці | Ні (`None`) |
| `list.reverse()` | Розгортає список задом наперед | Ні (`None`) |
| `list.copy()` | Робить поверхневу копію | Так (новий список) |
