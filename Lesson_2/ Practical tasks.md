# 📘 Практичні завдання: Методи списків у Python

Цей файл містить серію практичних завдань для відпрацювання базових та розширених методів роботи зі списками в Python.

---

## 📦 Завдання 1: 
* **Мета:** Освоїти методи `append()`, `insert()`, `remove()`, `pop()`.

### Умова:
1. Створіть список товарів: `inventory = ["Ноутбук", "Мишка", "Клавіатура"]`.
2. Додайте в кінець списку `"Монітор"`.
3. Вставте на друге місце (індекс `1`) товар `"Килимок"`.
4. Продано перший товар зі складу — видаліть його за допомогою `.pop()` та виведіть у повідомленні: `«Продано: <назва товару>»`.
5. Видаліть `"Мишка"` за назвою через `.remove()`.
6. Виведіть залишок товарів на складі.

---

## 📊 Завдання 2: 
* **Мета:** Освоїти методи `count()`, `index()`, `sort()`, `reverse()`.

### Умова:
Дано список балів учня за семестр: 
```python
grades = [10, 8, 12, 7, 12, 9, 11, 12, 6]
```

1. Порахуйте й виведіть, скільки разів учень отримав найвищий бал `12`.
2. Знайдіть позицію (індекс) першої оцінки `7`.
3. Відсортуйте оцінки за зростанням і виведіть список.
4. Розгорніть список оцінок у зворотний бік (за спаданням) методом `.reverse()`.

---

## 👥 Завдання 3: 
* **Мета:** Зрозуміти різницю між `extend()` та `append()`, освоїти `copy()`.

### Умова:
Є дві групи зареєстрованих користувачів:
```python
group_a = ["oleg", "ira", "maks"]
group_b = ["anna", "dmytro"]
```

1. Зробіть резервну копію `group_a` у змінну `backup_a` методом `.copy()`.
2. Об'єднайте `group_b` із `group_a` так, щоб у `group_a` були окремі імена, а не вкладений список всередині (порівняйте ефект `extend` проти `append`).
3. Переконайтеся, що `backup_a` залишився незмінним.

---

## 📝 Завдання 4: 
* **Мета:** Комбінація методів у єдиній інтерактивній програмі.

### Умова:
Напишіть скрипт черги завдань, що виконує такі кроки:

1. Створюється порожній список `tasks = []`.
2. За допомогою `append` додайте **3 завдання**, які вводить користувач через функцію `input()`.
3. Виведіть поточний список завдань із їхніми порядковими номерами.
4. Запитайте у користувача номер виконаного завдання, видаліть його зі списку через `.pop(index - 1)` і сповістіть: `«Завдання <назва> виконано та видалено!»`.
5. Відсортуйте завдання, що залишилися, за алфавітом через `.sort()` та виведіть фінальний список.
