# Теоретичний блок та детальні механіки

**Цикл** — це керуюча конструкція, яка повторює блок інструкцій (*тіло циклу*) доти, доки виконується певна умова або поки не вичерпаються елементи послідовності.

---

## Частина 1: Цикл з передумовою `while`

### Як це працює:
Перед кожною ітерацією Python перевіряє булеву умову:
1. Якщо умова повертає `True`, виконується блок коду всередині.
2. Після завершення тіла циклу інтерпретатор знову повертається на початок і перевіряє умову.
3. Як тільки умова повертає `False`, цикл завершується, а виконання коду продовжується з наступного рядка після циклу.

```python
# Базовий приклад: лічильник від 1 до 5
count = 1

while count <= 5:
    print(f"Ітерація: {count}")
    count += 1  # КРИТИЧНО: змінюємо керуючу змінну, інакше виникне нескінченний цикл!
```

> **Поширена пастка:** якщо забути рядок `count += 1`, виникає вічний цикл (*infinite loop*), оскільки $1 \le 5$ завжди даватиме `True`. Програма зависає і споживає 100% ядра процесора, зупинити її в консолі можна лише комбінацією <kbd>Ctrl</kbd> + <kbd>C</kbd>.

## Частина 2: Цикл по послідовності `for` та генератор `range()`

### Як це працює:
 у Python цикл `for` — це  ітератор. Він не оперує числовим індексом напряму, а послідовно бере кожен елемент із будь-якого ітерованого об'єкта (рядка, списку, кортежу, діапазону).

```python
# Ітерація по тексту
for letter in "Python":
    print(letter.upper())

# Ітерація по списку
fruits = ["яблуко", "груша", "слива"]
for fruit in fruits:
    print(f"Фрукт: {fruit}")
```

### Функція `range(start, stop[, step])`
Коли потрібна певна кількість повторень або лічильник, використовують `range()`:
* `range(stop)` — від `0` до `stop - 1` (з кроком 1).
* `range(start, stop)` — від `start` до `stop - 1`.
* `range(start, stop, step)` — від `start` до `stop - 1` із заданим кроком `step`.

```python
# 1. Тільки stop (генерує: 0, 1, 2)
for i in range(3):
    print(i, end=" ")  # 0 1 2

# 2. Start та stop (генерує: 2, 3, 4)
for i in range(2, 5):
    print(i, end=" ")  # 2 3 4

# 3. Крок step (парні числа: 2, 4, 6, 8)
for i in range(2, 10, 2):
    print(i, end=" ")  # 2 4 6 8

# 4. Зворотний відлік (зворотний крок: 5, 4, 3, 2, 1)
for i in range(5, 0, -1):
    print(i, end=" ")  # 5 4 3 2 1
```

## Частина 3: Керування потоком — `break`, `continue` та `else`

* **`break`** — миттєво перериває цикл і передає керування коду за його межами.
* **`continue`** — пропускає решту тіла поточної ітерації і відразу переходить до перевірки умови наступного кроку.
* **Блок `else` у циклах** — виконується тільки тоді, коли цикл завершився природним шляхом (без спрацювання `break`).

```python
# Пошук числа в циклі з перевіркою через else
target = 7
numbers = [1, 3, 5, 7, 9]

for n in numbers:
    if n == target:
        print(f"Знайдено число {target}!")
        break
else:
    print("Число не знайдено.")

# Приклад continue: друкуємо лише непарні числа
for x in range(1, 10):
    if x % 2 == 0:
        continue  # парні пропускаємо
    print(x, end=" ")  # виведе: 1 3 5 7 9
```

## Частина 4: Вкладені цикли (Nested Loops)

### Як це працює:
Внутрішній цикл виконує всі свої ітерації для кожної окремої ітерації зовнішнього циклу. Якщо зовнішній цикл має $N$ кроків, а внутрішній $M$, сумарно тіло внутрішнього циклу виконається $N \times M$ разів.

```python
# Таблиця множення 3x3
for row in range(1, 4):
    for col in range(1, 4):
        print(f"{row * col:2}", end=" ")
    print()  # перехід на новий рядок
```

## 5. Зведена таблиця вибору циклу

| Ситуація | Рекомендований цикл | Чому саме він |
| :--- | :--- | :--- |
| Кількість повторень відома заздалегідь ($N$ разів) | `for i in range(N)` | Компактний синтаксис, неможливо забути збільшити лічильник |
| Перебір елементів списку, рядка, словника | `for item in sequence` | Прямий доступ до елементів без ручної індексації |
| Кількість кроків невідома (залежить від дій користувача) | `while True` + `break` | Цикл триває, доки не спрацює конкретна умова завершення |
| Розрахунок до досягнення математичної точності / межі | `while condition:` | Зупиняється в момент виконання або порушення критерію |
