
## 1. Підготовка та реєстрація

* **Створення акаунта:**
  * Зайдіть на [github.com](https://github.com) та зареєструйтеся.
* **Встановлення Git на комп'ютер:**
  * Завантажте та встановіть [Git](https://git-scm.com/).
  * Для Windows під час встановлення можна сміливо залишати більшість налаштувань за замовчуванням (або обрати редактор за замовчуванням, наприклад, **VS Code**).

## 2. Первинне налаштування Git (Консоль / Термінал)

Після встановлення Git потрібно "подружити" його з комп'ютером і майбутнім акаунтом. Поясніть учню, що ці команди вводяться один раз:

```bash
git config --global user.name "Ваше Ім'я"
git config --global user.email "ваш_email@example.com"


Команди для гіта
git init — створення локального сховища в папці проєкту.

git status — перевірка стану (які файли змінені, які нові).

git add . — «знімок» змін (додавання файлів до стадії staged).

git commit -m "Коментар" — збереження фіксації історії з описом того, що було зроблено.

git push — відправка збереженого на сервер GitHub.

5. Перший проєкт "З нуля" (Практичний алгоритм)

Створити репозиторій на GitHub: Натиснути зелену кнопку New, ввести назву (наприклад, first-project), поставити галочку біля Add a README file, натиснути Create repository.

Клонувати репозиторій на ПК:

На сторінці репозиторію натиснути зелену кнопку Code, скопіювати URL.

У терміналі виконати: git clone <скопійований_URL>

Внести зміни: Відкрити цю папку у редакторі (наприклад, VS Code), створити файл index.html або main.py, написати туди кілька рядків коду.

Зберегти та відправити:

Bash
git add .
git commit -m "Додано первинний файл проєкту"
git push origin main
Перевірити результат: Оновити сторінку репозиторію на GitHub і побачити там новий файл.
