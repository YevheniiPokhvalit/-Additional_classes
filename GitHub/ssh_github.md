# Покрокова інструкція: Налаштування SSH-ключів для GitHub

Налаштування SSH-ключів 
---


## Крок 1. Генерація нового SSH-ключа
У терміналі виконайте таку команду (заміни пошту на ту, що прив'язана до твого акаунта GitHub):

```bash
ssh-keygen -t ed25519 -C "ваш_email@example.com"
```

## Крок 2. Запуск SSH-агента у фоновому режимі
Щоб система знала про ваш ключ, потрібно запустити агент:

*   **Для Windows (у Git Bash):**
    ```bash
    eval "$(ssh-agent -s)"
    ```

Після цього додайте створений приватний ключ до агента:
```bash
ssh-add ~/.ssh/id_ed25519
```

---

## Крок 3. Копіювання публічного ключа
Тепер потрібно скопіювати **публічний** ключ (файл із закінченням `.pub`), щоб додати його на GitHub.

*   **Команда для Windows (Git Bash):**
    ```bash
    clip < ~/.ssh/id_ed25519.pub
    ```
    *(Ключ автоматично збережеться в буфер обміну).*
---

## Крок 4. Додавання ключа на GitHub
1. Зайти на [github.com](https://github.com) і увійдіть в акаунт.
2. Натисніть на аватарку у верхньому правому кутку $\rightarrow$ оберіть **Settings** (Налаштування).
3. У лівому боковому меню знайдіть розділ **Access** і натисніть **SSH and GPG keys**.
4. Натисніть зелену кнопку **New SSH key** (або *Add SSH key*).
5. У полі **Title** введіть зрозумілу назву, наприклад: *Laptop Windows* або *MacBook Pro*.
6. У полі **Key type** залишіть *Authentication Key*.
7. У поле **Key** вставте скопійований раніше текст (Ctrl+V / Cmd+V).
8. Натисніть **Add SSH key**. (GitHub може попросити ввести пароль від акаунта для підтвердження).

---

## Крок 6. Перевірка зв'язку
Щоб переконатися, що все працює правильно, поверніться в термінал і виконайте команду:

```bash
ssh -T git@github.com
```

*   Термінал може запитати: *Are you sure you want to continue connecting (fingerprint)?* — напишіть **`yes`** і натисніть Enter.
*   Якщо все налаштовано правильно, ви побачите повідомлення:
    > **Hi [Ваш-Нікнейм]! You've successfully authenticated, but GitHub does not provide shell access.**
