## Частина 1: 

Досі всі дані зберігалися окремо (числа, списки, словники), а функції обробляли їх незалежно:

```python
# Процедурний підхід (словник + окрема функція)
hero_1 = {"name": "Воїн", "hp": 100}

def heal(character, amount):
    character["hp"] += amount

heal(hero_1, 20)
```

Якщо проєкт розростається, керувати десятками словників і функцій стає важко: дані не захищені, функції можна випадково викликати для неправильних структур даних.

* **ООП (Об'єктно-орієнтоване програмування)** — це підхід, який об'єднує дані (**стан**) та функції для роботи з ними (**поведінку**) в єдину сутність.
* **Клас (Class)** — це шаблон, креслення або рецепт. Він описує, які поля матиме сутність і що вона вмітиме робити. Сам по собі клас не займає місця в пам'яті під конкретні дані.
* **Об'єкт / Екземпляр (Object / Instance)** — це конкретний реальний предмет, створений за цим кресленням.

💡 **Аналогія:**
* *Клас* — це креслення автомобіля або формочка для печива.
* *Об'єкт* — це конкретний червоний автомобіль із номером `AE1234` або конкретне випечене печиво. За одним кресленням можна створити нескінченно багато унікальних об'єктів.

## Частина 2: Конструктор `__init__` та параметри стану

Щоб об'єкт при народженні отримав свої унікальні характеристики (ім'я, колір, запас здоров'я), використовують спеціальний метод — **конструктор `__init__`** (ініціалізатор).

* Починається і закінчується двома підкресленнями (**dunder-метод** / *magic method*).
* Викликається інтерпретатором автоматично в момент створення нового об'єкта.

```python
class Car:
    def __init__(self, brand, color):
        # Атрибути екземпляра (змінні, прив'язані до конкретного об'єкта)
        self.brand = brand
        self.color = color
        self.odometer = 0  # значення за замовчуванням при створенні

# Створення конкретних об'єктів (екземплярів):
car1 = Car("Toyota", "білий")
car2 = Car("BMW", "чорний")

print(car1.brand, car1.color)  # Виведе: Toyota білий
print(car2.brand, car2.color)  # Виведе: BMW чорний
```

## Частина 3: Що насправді таке `self`?

Це найчастіше запитання початківців: навіщо всюди писати `self` першим параметром?

* `self` — це **посилання на той конкретний об'єкт**, для якого в цей момент викликається метод.
* Коли викликається `car1.drive(50)`, Python під капотом перетворює це на виклик: `Car.drive(car1, 50)`. Тобто передає сам об'єкт `car1` першим аргументом.
* Завдяки `self` клас розуміє, чий саме пробіг або чий баланс треба змінити — першого автомобіля чи другого.

> ⚠️ Назву `self` можна теоретично замінити іншим словом, але за стандартом **PEP 8** це суворе правило спільноти Python — завжди писати виключно `self`.

## Частина 4: Методи класу (поведінка об'єкта)

**Методи** — це функції, які визначені всередині класу і керують станом об'єкта.

* 🏷️ **Атрибути** відповідають на питання: *«Який об'єкт?» / «Що в нього є?»* (іменники: `name`, `hp`, `speed`).
* ⚡ **Методи** відповідають на питання: *«Що об'єкт робить?»* (дієслова: `drive()`, `take_damage()`, `save()`).

```python
class Car:
    def __init__(self, brand, fuel):
        self.brand = brand
        self.fuel = fuel

    # Метод пересування
    def drive(self, distance):
        fuel_needed = distance * 0.1
        if self.fuel >= fuel_needed:
            self.fuel -= fuel_needed
            print(f"{self.brand} проїхав {distance} км. Залишок пального: {self.fuel:.1f} л")
        else:
            print(f"{self.brand} не може їхати: не вистачає пального!")

    # Метод заправки
    def refuel(self, liters):
        self.fuel += liters
        print(f"{self.brand} заправлено на {liters} л. Всього пального: {self.fuel} л")

# Робота з об'єктом:
my_car = Car("Skoda", 20)
my_car.drive(150)   # витратить 15 л, лишиться 5 л
my_car.drive(100)   # бракує пального
my_car.refuel(30)   # заправили
```

## Частина 5: Метод `__str__` (рядкове представлення)

Якщо спробувати надрукувати об'єкт без `__str__`:
```python
print(my_car)  # Виведе: <__main__.Car object at 0x7f8b901a3cd0> (незрозуміла адреса пам'яті)
```

Метод `__str__` повертає зручний і зрозумілий рядок щоразу, коли об'єкт передають у `print()` або перетворюють на рядок через `str()`:

```python
class Car:
    def __init__(self, brand, color):
        self.brand = brand
        self.color = color

    def __str__(self):
        return f"Автомобіль {self.brand} ({self.color} колір)"

my_car = Car("Audi", "синій")
print(my_car)  # Виведе: Автомобіль Audi (синій колір)
```

## 3. Зведена таблиця базових понять ООП

| Поняття | Що це таке | Приклад у синтаксисі |
| :--- | :--- | :--- |
| **Клас** | Шаблон / креслення майбутнього об'єкта | `class Hero:` |
| **Об'єкт (екземпляр)** | Конкретний створений екземпляр класу | `player = Hero("Артур")` |
| **Конструктор `__init__`** | Метод ініціалізації стану об'єкта | `def __init__(self, name):` |
| **`self`** | Посилання на поточний об'єкт у пам'яті | `self.name = name` |
| **Атрибут** | Змінна, що зберігає стан об'єкта | `self.health = 100` |
| **Метод** | Функція всередині класу, що описує дію | `def attack(self, target):` |
| **`__str__`** | Метод для людиночитабельного виводу в `print()` | `def __str__(self):` |
