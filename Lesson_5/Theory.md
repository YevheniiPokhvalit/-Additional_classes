# Теоретичний блок 

## Частина 1: Що таке функція та як вона влаштована

**Функція** — це іменований ізольований блок коду, призначений для багаторазового виконання конкретної підзадачі.

### Метафора «чорної скриньки»

Уявіть соковитискач. Ви завантажуєте в нього апельсини (вхідні аргументи), всередині працює прихований механізм (тіло функції), а на виході ви отримуєте склянку соку (результат `return`). Соковитискачу байдуже, де ви взяли фрукти — він просто виконує свій алгоритм.

```python
# Оголошення функції (Function Definition)
def greet():
    print("Привіт! Ласкаво просимо до програми.")

# Виклик функції (Function Call)
greet()
```

## Частина 2: Параметри та аргументи

Терміни часто плутають, але між ними є принципова різниця:

* **Параметри** — це змінні, зазначені в круглих дужках під час оголошення функції (`def calculate_area(width, height):`). Це змінні-«контейнери».
* **Аргументи** — це конкретні значення, які передаються у функцію під час її виклику (`calculate_area(5, 10)`).

### 1. Позиційні та іменовані (keyword) аргументи

* **Позиційні:** зіставляються за порядком передачі. Перший аргумент потрапляє в перший параметр, другий — у другий.
* **Іменовані:** явно вказують ім'я параметра: `param=value`. Дозволяють змінювати порядок передачі або покращувати читабельність коду.

```python
def describe_pet(animal_type, pet_name):
    print(f"У мене є {animal_type} на ім'я {pet_name}.")

# Позиційний виклик (порядок важливий!)
describe_pet("кіт", "Барсик")

# Іменований виклик (порядок можна змінювати)
describe_pet(pet_name="Рекс", animal_type="пес")
```

### 2. Параметри зі значенням за замовчуванням (Default values)

Якщо аргумент часто є однаковим, йому можна задати значення за замовчуванням.

> **Залізне правило Python:** параметри з дефолтними значеннями завжди мають іти після обов'язкових позиційних параметрів.

```python
def calculate_discount(price, discount=10):
    final_price = price - (price * discount / 100)
    return final_price

print(calculate_discount(1000))       # використає знижку 10% за замовчуванням -> 900.0
print(calculate_discount(1000, 25))   # перезапише дефолтну знижку -> 750.0
```

> **Поширена пастка зі змінними дефолтами:** ніколи не використовуйте змінювані типи (`list`, `dict`) як аргументи за замовчуванням (`def add_item(item, lst=[])`). Цей список створиться один раз під час компіляції функції і буде накопичувати дані між різними викликами. Замість цього пишіть `def add_item(item, lst=None):` і всередині перевіряйте `if lst is None: lst = []`.

## Частина 3: Механіка return проти print()

Це головний бар'єр для початківців: плутати відображення інформації на екрані та повернення значення у програму.

* `print()` — це просто «динамік». Він показує текст на моніторі для людини. Код програми не може використати те, що вивів `print`.
* `return` — це значення, яке підставляється замість виклику функції. Його можна зберегти у змінну, передати в іншу функцію, використати в математичному рівнянні або умові `if`.

```python
# Помилковий підхід через print:
def bad_add(a, b):
    print(a + b)

res = bad_add(5, 5)  # На екрані з'явиться 10
print(res)           # Але в змінній res лежить None!
# total = res * 2    # Помилка TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'

# Правильний підхід через return:
def good_add(a, b):
    return a + b

res = good_add(5, 5) # res = 10
total = res * 2      # total = 20 (працює штатно)
```

### Особливості return:

1. **Миттєве завершення роботи:** як тільки інтерпретатор доходить до інструкції `return`, виконання функції негайно зупиняється. Будь-який код під ним у поточному блоці ігнорується.
2. **Значення за замовчуванням:** функція без `return` завжди неявно повертає `None`.
3. **Повернення кількох значень:** Python дозволяє повертати кілька значень через кому. Насправді він автоматично упаковує їх у незмінний кортеж (`tuple`).

```python
def min_and_max(numbers):
    return min(numbers), max(numbers)  # повертає кортеж (min, max)

minimum, maximum = min_and_max([4, 18, 2, 99, 12])  # множинне розпакування
print(f"Мін: {minimum}, Макс: {maximum}")
```

## Частина 4: Області видимості (Scope) та правило LEGB

Область видимості визначає, в якій частині програми змінна доступна для читання та модифікації.

* **Локальна область (Local Scope):**  
  Будь-яка змінна, створена всередині тіла функції (включно з її параметрами), існує лише під час роботи цієї функції. Коли функція завершує роботу, локальні змінні знищуються в пам'яті. Зовнішній код не має до них доступу.
* **Глобальна область (Global Scope):**  
  Змінні, створені на рівні головного файлу (поза функціями). Вони доступні для читання звідусіль.

### Правило пошуку імен LEGB:

Коли всередині функції звертаються до назви змінної, Python шукає її в такому порядку:

1. **L (Local)** — локально всередині поточної функції.
2. **E (Enclosing)** — у зовнішніх функціях, якщо є вкладеність.
3. **G (Global)** — на глобальному рівні скрипта.
4. **B (Built-in)** — серед вбудованих функцій Python (`print`, `len`, `int` тощо).

```python
x = 100  # Глобальна змінна

def test():
    x = 10  # Локальна змінна, яка перекриває (shadows) глобальну
    print("Всередині функції x =", x)  # 10

test()
print("Ззовні функції x =", x)          # 100 (глобальна не змінилася!)
```

### Ключове слово global:

Дозволяє перезаписувати глобальну змінну зсередини функції (`global x`).

> **Методична порада для учня:**  
> Уникайте `global`. Використання глобальних змінних у функціях ламає інкапсуляцію, створює приховані залежності та призводить до непередбачуваних помилок у великих проєктах. Якщо функції потрібні дані ззовні — передавайте їх через параметри. Якщо потрібно передати результат назовні — використовуйте `return`.
