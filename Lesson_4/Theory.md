# 📙 Теоретичний блок та приклади

**Словник (dict)** — це змінювана (mutable), невпорядкована за індексами (але зі збереженням порядку додавання, починаючи з Python 3.7) колекція пар «ключ: значення».

* **Вимога до ключів:** ключ має бути незмінним (immutable) та хешованим (hashable) типом даних: `str`, `int`, `float`, `tuple`, `bool`. Списки та інші словники бути ключами **не можуть**.
* **Значення:** будь-який тип даних без жодних обмежень (списки, словники, числа, об'єкти).

## 🛠️ Варіанти створення
```python
empty_dict = {}
student = {"name": "Олексій", "grade": 11, "skills": ["Python", "HTML"]}
coords = dict(x=10, y=20)  # Створення через конструктор
```

---

## 🔍 Читання та доступ до даних

* **Квадратні дужки `d[key]`:** швидкий доступ. Якщо ключа немає в словнику — виникає фатальна помилка `KeyError`.
* **Метод `.get(key, default=None)`:** безпечний доступ. Якщо ключа немає — повертає `None` або вказане дефолтне значення без падіння програми.
* **Оператор `in`:** перевіряє наявність саме серед ключів за найшвидший час O(1).

**Приклад використання:**
```python
user = {"login": "alex_pro", "role": "admin"}

print(user["login"])         # Виведе: "alex_pro"
# print(user["email"])       # Помилка KeyError: 'email'

print(user.get("email"))                 # Виведе: None
print(user.get("email", "not_provided")) # Виведе: "not_provided"

if "role" in user:
    print("Роль визначена!")
```

## 📚 Повний довідник вбудованих методів `dict`

Усього в Python є **11 стандартних методів** для роботи зі словниками.

### 1. Отримання та встановлення за замовчуванням

* `.get(key[, default])` — повертає значення ключа або значення `default`, якщо ключ відсутній.
* `.setdefault(key[, default])` — якщо ключ є в словнику, повертає його значення. Якщо ключа немає — створює його зі значенням `default` і повертає це значення.

**Приклад використання:**
```python
inventory = {"apples": 10}

val = inventory.setdefault("apples", 0)   # Вже є -> поверне 10, не змінить словник
val2 = inventory.setdefault("oranges", 5) # Немає -> додасть 'oranges': 5 і поверне 5

# Стан inventory: {'apples': 10, 'oranges': 5}
```

### 2. Оновлення та злиття

* `.update([other])` — оновлює словник парами з іншого словника або ітерованого об'єкта пар. Перезаписує наявні ключі та додає нові.
* *(Варто знати: починаючи з Python 3.9+, також доступний оператор об'єднання: `d3 = d1 | d2`).*

**Приклад використання:**
```python
profile = {"name": "Ігор", "age": 16}
profile.update({"age": 17, "city": "Дніпро"})

# Стан profile: {'name': 'Ігор', 'age': 17, 'city': 'Дніпро'}
```

### 3. Видалення даних

* `.pop(key[, default])` — видаляє вказаний ключ і повертає його значення. Якщо ключа немає і `default` не задано — виникає `KeyError`.
* `.popitem()` — видаляє та повертає останню додану пару у вигляді кортежу `(key, value)`. Якщо словник порожній — викликає `KeyError`.
* `.clear()` — повністю очищає словник (залишає порожнім `{}`).
* *(Інструкція `del d[key]` також видаляє ключ, але без повернення значення).*

**Приклад використання:**
```python
stats = {"hp": 100, "mana": 50, "armor": 15}

hp_value = stats.pop("hp")             # hp_value = 100
last_item = stats.popitem()            # Поверне: ('armor', 15)
stats.pop("energy", 0)                 # Помилки немає, поверне 0

del stats["mana"]                      # Видалення ключа без повернення значення
stats.clear()                          # Очищення. Стан stats: {}
```

### 4. Копіювання та створення

* `.copy()` — робить поверхневу копію словника.
* `dict.fromkeys(iterable[, value])` — метод класу, який створює новий словник із ключами з послідовності `iterable` та спільним значенням `value` (за замовчуванням `None`).

**Приклад використання:**
```python
keys = ["ua", "en", "pl"]
langs = dict.fromkeys(keys, 0)

# Стан langs: {'ua': 0, 'en': 0, 'pl': 0}
```

### 5. Перегляд вмісту (View-об'єкти)

* `.keys()` — повертає dynamic view (динамічну колекцію) усіх ключів.
* `.values()` — повертає view усіх значень.
* `.items()` — повертає view пар у вигляді кортежів `(key, value)`.

**Приклад використання:**
```python
prices = {"хліб": 24, "молоко": 38, "сир": 95}

# Ітерація по парах ключ-значення (найпопулярніший патерн)
for product, price in prices.items():
    print(f"{product} коштує {price} грн")

total = sum(prices.values())  # Поверне: 157
```

## 📊 3. Зведена шпаргалка методів

| Метод | Що виконує | Результат повернення |
| :--- | :--- | :--- |
| `d.get(k, def)` | Безпечний пошук значення | Значення або `def` |
| `d.setdefault(k, def)` | Пошук, а в разі відсутності — запис | Поточне або нове значення |
| `d.update(other)` | Масове оновлення / додавання елементів | `None` |
| `d.pop(k[, def])` | Видалення ключа | Видалене значення або `def` |
| `d.popitem()` | Видалення останньої доданої пари | Кортеж `(key, value)` |
| `d.clear()` | Повне очищення словника | `None` |
| `d.copy()` | Поверхнева копіювання | Новий словник `dict` |
| `d.keys()` | Колекція (view) всіх ключів | `dict_keys` |
| `d.values()` | Колекція (view) всіх значень | `dict_values` |
| `d.items()` | Колекція пар ключ-значення | `dict_items` з кортежами |
| `dict.fromkeys(seq, v)` | Фабрика словника зі списку ключів | Новий словник `dict` |
