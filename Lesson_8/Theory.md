## Частина 1: Що таке модуль та як працює `import`

**Модуль у Python** — це будь-який файл із розширенням `.py`, який містить готові функції, класи та змінні. Замість того, щоб писати тисячі рядків коду в одному файлі або самостійно програмувати складні математичні формули, ми підключаємо готові модулі.

### Три категорії модулів:

1. **Вбудовані (Standard Library):** встановлюються разом із Python (`math`, `random`, `datetime`, `json`, `os`).
2. **Власні модулі:** інші `.py` файли у вашому проєкті.
3. **Зовнішні пакети:** бібліотеки від сторонніх розробників, що встановлюються через менеджер `pip` (`requests`, `pygame`, `pandas`).

---

### Чотири способи підключення модуля:

```python
# 1. Базовий імпорт всього модуля (найбезпечніший варіант)
import math
print(math.sqrt(16))  # Звернення через крапку: модуль.функція()

# 2. Імпорт із псевдонімом (alias) — скорочує довгі назви
import datetime as dt
now = dt.datetime.now()

# 3. Точковий імпорт конкретних функцій (не потрібно писати назву модуля)
from random import randint, choice
print(randint(1, 10))

# 4. Імпорт усього вмісту зірочкою (АНТИПАТЕРН — краще уникати)
from math import *
# Чому погано: засмічує простір імен і може непомітно перезаписати ваші власні функції.
```

---

### Огляд найкорисніших стандартних модулів:

* **Модуль `random`** (генерація випадковостей — основа для ігор та симуляцій):
  * `random.randint(a, b)` — випадкове ціле число від `a` до `b` включно.
  * `random.choice(seq)` — випадковий елемент зі списку або рядка.
  * `random.shuffle(list)` — перемішує список на місці (як колоду карт).

* **Модуль `datetime`** (робота з датами та часом):
  * `datetime.datetime.now()` — поточна дата і точний час.
  * `.strftime("%d.%m.%Y %H:%M")` — форматування дати у красивий рядок.

```python
import random
from datetime import datetime

loot = ["Меч", "Щит", "Зілля", "Золото"]
print("Випав предмет:", random.choice(loot))

current_time = datetime.now().strftime("%d.%m.%Y о %H:%M:%S")
print("Час події:", current_time)
```

## Частина 2: Формат JSON — стандарт зберігання структурованих даних

якщо в гравця є ім'я, рівень, список предметів у рюкзаку та словник характеристик? Парсити це через `.split()` — неефективно та складно.

Для цього використовують **JSON** (*JavaScript Object Notation*) — текстовий формат обміну даними, який візуально майже на 100% повторює синтаксис словників та списків Python.

### Таблиця відповідності типів ($Python \leftrightarrow JSON$)

| Тип у Python | Тип у JSON | Приклад у JSON |
| :--- | :--- | :--- |
| `dict` | object | `{"name": "Олег", "lvl": 5}` |
| `list`, `tuple` | array | `["sword", "shield"]` |
| `str` | string | `"Текст тільки у подвійних лапках"` |
| `int`, `float` | number | `42`, `3.14` |
| `True` / `False` | boolean | `true` / `false` *(з малої літери)* |
| `None` | null | `null` |

---

### Чотири головні функції модуля `json`:

> **Підказка для запам'ятовування:**  
> Різниця полягає в літері **`s`** на кінці (**s**tring — робота з рядком у пам'яті; без **s** — робота напряму з файлом).

1. `json.dump(obj, file)` — записує об'єкт Python напряму у відкритий файл.
2. `json.load(file)` — читає JSON-дані з файлу і перетворює їх назад на словник/список Python.
3. `json.dumps(obj)` — перетворює об'єкт Python на JSON-рядок (`str`).
4. `json.loads(str)` — перетворює JSON-рядок на об'єкт Python.

#### Два «золоті» параметри при записі (`dump` / `dumps`):
* `indent=4` — додає відступи та переноси рядків, щоб файл був зручним для читання людиною, а не злипався в один довгий рядок.
* `ensure_ascii=False` — **критично для кирилиці!** Без цього параметра українські літери перетворяться на юнікод-послідовності вигляду `\u041f\u0440\u0438\u0432\u0456\u0442`.

```python
import json

player_data = {
    "nickname": "Козак_2026",
    "level": 12,
    "is_active": True,
    "inventory": ["Шабля", "Кобза", "Енергетик"]
}

# 1. Збереження у файл (Серіалізація)
with open("save.json", "w", encoding="utf-8") as file:
    json.dump(player_data, file, indent=4, ensure_ascii=False)

# 2. Завантаження з файлу (Десеріалізація)
with open("save.json", "r", encoding="utf-8") as file:
    loaded_player = json.load(file)

print(type(loaded_player))            # <class 'dict'>
print(loaded_player["inventory"][0])  # Шабля
```

> ⚠️ **Критичне попередження **  
> Ніколи не називайте свій робочий файл `json.py` або `random.py`! Коли ви напишете `import json`, Python спробує імпортувати ваш власний файл замість системної бібліотеки, і програма впаде з помилкою:  
> `AttributeError: module 'json' has no attribute 'dump'`
