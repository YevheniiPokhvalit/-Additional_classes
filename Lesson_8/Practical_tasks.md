

# Практичні завдання на закріплення

### Завдання 1: «Генератор випадкових паролів із міткою часу»
* **Мета:** робота з модулями `random` та `datetime`.
* **Умова:**
  1. Підключіть модулі `random` та `datetime`.
  2. Дано рядок доступних символів:
     ```python
     chars = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789!@#$%"
     ```
  3. Запитайте у користувача бажану довжину пароля $N$.
  4. Згенеруйте пароль довжиною $N$ за допомогою `random.choice(chars)`.
  5. Виведіть згенерований пароль та точну дату й час його створення у форматі `ДД.ММ.РРРР ГГ:ХХ:СС`.

---

### Завдання 2: «Конфігурація застосунку» (Базовий `json.dump` та `json.load`)
* **Мета:** запис та читання словника з JSON-файлу з підтримкою кирилиці.
* **Умова:**
  1. Створіть словник налаштувань `settings`:
     * `"theme": "dark"`
     * `"language": "Українська"`
     * `"notifications": True`
     * `"volume": 80`
  2. Збережіть цей словник у файл `config.json` із відступами `indent=4` та коректним відображенням української мови.
  3. Зчитайте файл назад у нову змінну `loaded_config`.
  4. Змініть гучність `"volume"` на `100`, перезбережіть файл і виведіть оновлений словник у консоль.

---

### Завдання 3: «Стійке завантаження бази даних» (`json` + `try-except`)
* **Мета:** безпечне читання JSON, обробка відсутності файлу (`FileNotFoundError`) та пошкодженого формату (`json.JSONDecodeError`).
* **Умова:**  
  Напишіть функцію `load_database(filename)`, яка:
  1. Намагається відкрити та прочитати JSON-файл.
  2. Якщо файлу не існує (`FileNotFoundError`) — виводить повідомлення `«Файл не знайдено. Створюємо порожню базу.»` і повертає порожній список `[]`.
  3. Якщо файл пошкоджений або порожній (`json.JSONDecodeError`) — виводить `«Помилка читання формату JSON!»` і також повертає `[]`.
  4. Протестуйте функцію на неіснуючому файлі.

---

### Завдання 4: Мініпроєкт — «Трекер витрат зі збереженням історії»
* **Мета:** об'єднання модулів `json`, `datetime`, списків та словників у повноцінний інструмент.
* **Умова:**  
  Напишіть програму, яка веде облік витрат у файлі `expenses.json`:
  1. При запуску програма завантажує список попередніх витрат із файлу `expenses.json` (якщо файлу немає — починає з порожнього списку `[]`).
  2. Запитує у користувача назву категорії (наприклад, `"Кава"`) та суму витрати (наприклад, `65.0`).
  3. Формує словник запису:
     ```python
     {"category": ..., "amount": ..., "date": "<поточна дата і час>"}
     ```
  4. Додає новий запис до списку і зберігає оновлений список назад у `expenses.json`.
  5. Виводить загальну суму всіх витрат за весь час та список останніх операцій.
